# ColorOS 增强

面向 OPPO Find X7 Ultra（PHY110）、ColorOS 17.0.0.100 CN01 / Android 17 API 37 的独立 LSPosed 模块。

主界面包含五个设置入口：

| 入口 | 功能 |
| --- | --- |
| 分屏与小窗 | 应用分屏、小窗数量与比例、圆角与阴影、优先小窗、应用过滤、独立贴边数量与展开恢复 |
| OPPO 互联 | 电脑投屏码率、分辨率、DPI、帧率请求，以及解除普通窗口截图录屏限制 |
| AOD | 初始亮度、运行倍率、系统默认选项、显示时长、全天全景、单击防误触、低光保持与功能运行状态 |
| 隔空手势 | 解锁隔空滑动、暂停／播放设置，保留本机原生识别引擎；系统手势设置由 ColorOS 管理 |
| 联网管理 | 补齐可管理系统应用的 WLAN／移动数据选项，设置入口由 ColorOS 管理 |

## 当前版本

1.6.1 延续联网选项解锁，并移除模块内的应用选择器、组件重启和手势学习入口；所有模块及 AOD 子页面统一为同一套原生设置界面。既有配置键、包身份与签名保留，可覆盖安装。详见 [联网适配与验证](docs/NETWORK_CONTROL_1.6.0.md)。1.5.0 的功能修复记录保留在 [适配优化](docs/OPTIMIZATION_1.5.0.md)。

## 安装与使用

1. 安装 `dist/ColorOSEnhance_PHY110_v1.6.1.apk`。
2. 在支持 modern API 102 的 LSPosed 中启用模块，勾选系统框架（`system`）、屏幕投屏（`com.oplus.cast`）、系统界面（`com.android.systemui`）、息屏（`com.oplus.aod`）、手势体感（`com.oplus.gesture`）和流量管理（`com.oplus.trafficmonitor`）。不需要勾选 AONService。
3. 停用其他重叠功能模块，更新后重启手机并打开“ColorOS 增强”。

截图录屏开关位于 **OPPO 互联 → 截图与录屏**，与投屏优化总开关独立。修改捕获开关、窗口比例、圆角或阴影后，重新打开目标应用。投屏参数改变后，停止并重新发起电脑投屏。

建议投屏保留原生协商分辨率、请求 60 帧、均衡码率和当前 DPI。本机物理尺寸为 1440×3168；有效 DPI 从当前显示配置读取。实际发送帧率、码率按内容和网络变化，90/120 帧请求不代表始终达到对应帧率。

分屏、投屏与 AOD 增强在全新安装时默认关闭，AOD 亮度和时长默认跟随系统。已有明确保存的设置保留，其他设备的新安装不会读取另一应用的私有配置。

联网解锁默认关闭，开启后重新进入系统页面。原本已经有选项的普通应用保留原生控制；共享 UID 的应用共用规则，核心身份与企业管理限制保持原样。关闭解锁不会清空已经设置的禁用规则。

隔空手势解锁默认关闭。系统手势开关和支持的应用由 ColorOS 管理；模块只提供额外设置入口，不提供组件重启或手势学习操作。

## 配置与恢复

分屏与投屏使用 `window_capture` 配置组；AOD 使用独立的 `aod_config` 配置组。分屏页面恢复默认仅处理窗口设置；恢复投屏参数保留截图开关；“恢复 AOD 系统默认”仅处理 AOD。页面分别显示配置同步与宿主加载状态；窗口状态还区分接口触发及最近实际观察结果。

AOD 的“全天全景息屏”包含后台全天能力和系统设置入口，仍需在系统中选择“全天显示”。仅显示入口的独立选择保留在高级选项。切换后自动同步，下一次息屏生效；关闭恢复原生能力，不再需要为切换功能重启系统界面。

“贴边应用数量”与“同时开启的小窗数量”分别保存。新设置不要求开启强制多窗口、记住贴边或前台保活，也不控制电脑投屏应用窗口数量。升级后首次使用需重启手机加载新增接口，之后修改数量可自动同步。

可在对应页面恢复设置，或停用模块后重启。模块不替换系统文件、不写入分屏开发者选项。电脑工程的 `keystore/` 和 `keystore.properties` 用于后续同签名更新，交付源码不包含私钥与密码。

## 构建

需要 JDK 21、Android SDK 37 / Build Tools 37.0.0。工程使用 AGP 9.3.1、Gradle 9.6.1、Compose 插件 2.4.0，以及 libxposed API / Service 102.0.0。正式包仅包含 arm64-v8a。

在 `local.properties` 配置 `sdk.dir`，运行：

```powershell
.\gradlew.bat :app:assembleRelease :app:lintRelease
.\gradlew.bat :app:testDebugUnitTest
```

Windows 上建议在不含中文的路径构建，以避开测试进程的路径识别问题。Release 在存在签名配置时使用个人签名，否则生成未签名包。`probe/` 是独立测试应用，不是正式模块的运行依赖。
