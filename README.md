# ColorOS 增强

面向 OPPO Find X7 Ultra（PHY110）、ColorOS 17.0.0.100 CN01 / Android 17 API 37 的独立 LSPosed 模块。

主界面包含八个设置入口：

| 入口 | 功能 |
| --- | --- |
| 分屏与小窗 | 应用分屏、小窗数量与比例、圆角与阴影、优先小窗、独立贴边数量与展开恢复 |
| OPPO 互联 | 电脑投屏码率、分辨率、DPI、帧率请求，以及解除普通窗口截图录屏限制 |
| AOD | 初始亮度、运行倍率、系统默认选项、显示时长、全天全景、单击防误触、低光保持与功能运行状态 |
| 隔空手势 | 解锁隔空滑动、暂停／播放设置，保留本机原生识别引擎；系统手势设置由 ColorOS 管理 |
| 联网管理 | 补齐可管理系统应用的 WLAN／移动数据选项，设置入口由 ColorOS 管理 |
| 小布记忆 | 恢复微信自动记账支持，保留系统总开关、应用开关与原生账单识别 |
| 相机与相册 | AI 修图师、云端灵感推荐与专业视频 Log，使用系统原生处理 |
| 声音分轨 | 解除原生声音分轨的应用白名单限制，保留原生分轨面板与音效冲突检查 |

## 当前版本

2.1.2 修复声音分轨在重启后被 ColorOS 关联启动管理拦截的问题。仅在声音开关开启时，允许本机音效共享进程访问本模块指定的声音组件；保留原生前置限制，不修改系统关联启动名单。另补充电脑投屏切换捕获开关后需要重连的提示。实机回归记录见 [2.1.2 全面回归](docs/FULL_REGRESSION_2.1.2.md)。

本轮尚未证实圆角／阴影和自由调整比例的实际差异；记账实际生成记录已由用户确认，但诊断计数未捕获该事件。报告分别列出通过项、未证实项及未完成的长期测试，不将接口加载视为功能验证通过。

2.1.1 修复哔哩哔哩的分轨应用分类限制，以及后台连接中断导致番茄小说等新增应用恢复为不支持的问题。详见 [声音分轨修复](docs/SOUND_FIX_2.1.1.md)。

2.1.0 新增“相机与相册 → 解锁 Log 视频”和独立“声音分轨”入口。RAW、RAW MAX、专业视频和长曝光原生已有，不重复加入解锁开关。详见 [相机原生能力核对与声音分轨适配](docs/CAMERA_SOUND_2.1.0.md)。

## 安装与使用

1. 安装 `dist/ColorOSEnhance_PHY110_v2.1.2.apk`。
2. 在支持 modern API 102 的 LSPosed 中启用模块，勾选系统框架（`system`）、屏幕投屏（`com.oplus.cast`）、系统界面（`com.android.systemui`）、息屏（`com.oplus.aod`）、手势体感（`com.oplus.gesture`）、流量管理（`com.oplus.trafficmonitor`）、记账服务（`com.oplus.gleanerservice`）、相册（`com.coloros.gallery3d`）、相机（`com.oplus.camera`）、音效（`com.oplus.audio.effectcenter`）与 Atlas 服务（`com.oplus.atlas`）。不需要勾选 AONService 或微信。
3. 停用其他重叠功能模块，更新后重启手机并打开“ColorOS 增强”。

截图录屏开关位于 **OPPO 互联 → 截图与录屏**，与投屏优化总开关独立。修改捕获开关、窗口比例、圆角或阴影后，重新打开目标应用。投屏参数或捕获开关改变后，停止并重新发起电脑投屏，以刷新互联缓存的敏感页面保护状态。

建议投屏保留原生协商分辨率、请求 60 帧、均衡码率和当前 DPI。本机物理尺寸为 1440×3168；有效 DPI 从当前显示配置读取。实际发送帧率、码率按内容和网络变化，90/120 帧请求不代表始终达到对应帧率。

分屏、投屏与 AOD 增强在全新安装时默认关闭，AOD 亮度和时长默认跟随系统。已有明确保存的设置保留，其他设备的新安装不会读取另一应用的私有配置。

联网解锁默认关闭，开启后重新进入系统页面。原本已经有选项的普通应用保留原生控制；共享 UID 的应用共用规则，核心身份与企业管理限制保持原样。关闭解锁不会清空已经设置的禁用规则。

隔空手势解锁默认关闭。系统手势开关和支持的应用由 ColorOS 管理；模块只提供额外设置入口，不提供组件重启或手势学习操作。

微信自动记账恢复默认关闭。开启后，在小布记忆的系统设置中进入“自动记账”，开启总开关和“微信”。初次出现的微信开关默认关闭，已有的系统选择保持不变。修改模块开关后重新进入系统页面，后台同步刷新监听；关闭后恢复原生列表，已生成账单与原生应用开关保留。

支付结果页的 OCR 需要确认支付成功及明确的人民币金额，存疑结果不提交。原生交易去重仍保留；只有可见订单号或完整支付时间等证据足够时才纠正误判，缺少证据时无法保证区分短时间内同金额、同收款方的两笔付款。

AI 修图师和云端灵感推荐默认关闭。AI 修图师开启后，在相册选择照片并进入“编辑 → AI 编辑 → AI 修图师”；云端灵感推荐开启后，打开相机并进入原生灵感推荐入口。修改开关后退出对应应用并重新进入；首次新增作用域时重新打开应用。关闭恢复原生入口，已保存的图片保留。联网授权、账号、服务额度及图片限制仍由系统应用处理。云端灵感推荐与本地实时灵感构图分开，本地构图引擎不在本模块中。

Log 默认关闭。开启后重启相机进程，在“更多 → 专业视频 → 帧率和画幅 → 格式”中选择 Log。本机验证为 1080p、30 帧、HEVC Main10；这不代表解锁 O-Log2。Log 选择仅在当前相机进程有效，重启后从 SDR 开始，避免停用模块后留下隐藏格式。开关关闭后重启相机进程，恢复原生功能表。

声音分轨默认关闭，需要授予本应用 Root 权限。显示“已生效”后重新打开系统原生声音分轨面板；空间音效、输出设备和媒体场景的原生判断保留。关闭后恢复原生应用范围，并停止新增应用的分轨；停用 LSPosed 模块后重启声音组件或手机也会恢复。

## 配置与恢复

分屏与投屏使用 `window_capture` 配置组；AOD 使用独立的 `aod_config` 配置组。分屏页面恢复默认仅处理窗口设置；恢复投屏参数保留截图开关；“恢复 AOD 系统默认”仅处理 AOD。页面分别显示配置同步与宿主加载状态；窗口状态还区分接口触发及最近实际观察结果。

AOD 的“全天全景息屏”包含后台全天能力和系统设置入口，仍需在系统中选择“全天显示”。仅显示入口的独立选择保留在高级选项。切换后自动同步，下一次息屏生效；关闭恢复原生能力，不再需要为切换功能重启系统界面。

“贴边应用数量”与“同时开启的小窗数量”分别保存。新设置不要求开启强制多窗口、记住贴边或前台保活，也不控制电脑投屏应用窗口数量。升级后首次使用需重启手机加载新增接口，之后修改数量可自动同步。

可在对应页面恢复设置，或停用模块后重启。模块不写入系统分区、不写入分屏开发者选项。声音分轨通过临时挂载副本并调用原生重载更新内存策略，重载后立即卸载；关闭或声音宿主退出时重新加载原生策略。电脑工程的 `keystore/` 和 `keystore.properties` 用于后续同签名更新，交付源码不包含私钥与密码。

## 构建

需要 JDK 21、Android SDK 37 / Build Tools 37.0.0。工程使用 AGP 9.3.1、Gradle 9.6.1、Compose 插件 2.4.0，以及 libxposed API / Service 102.0.0。正式包仅包含 arm64-v8a。

在 `local.properties` 配置 `sdk.dir`，运行：

```powershell
.\gradlew.bat :app:assembleRelease :app:lintRelease
.\gradlew.bat :app:testDebugUnitTest
```

Windows 上建议在不含中文的路径构建，以避开测试进程的路径识别问题。Release 在存在签名配置时使用个人签名，否则生成未签名包。`probe/` 是独立测试应用，不是正式模块的运行依赖。
