# 1.5.0 适配优化

适配设备：OPPO Find X7 Ultra（PHY110），ColorOS `PHY110_17.0.0.100(CN01)`，Android 17 / API 37。此前的关闭／开启对照保留在 [行为审计](BEHAVIOR_AB_AUDIT.md)，本页记录后续修复，不改写历史试次。

## 启动与贴边恢复

- 桌面启动按实际调用进程识别，兼容系统未传入来源 Activity 的情况。桌面、通知、跨应用跳转使用各自开关；同应用内部跳转保留系统选项。
- 过滤作用于目标应用。桌面不再因自身属于排除包而使目标应用策略失效。应用锁、加密应用、锁屏以及明确指定的其他窗口模式仍交给原生处理。
- 记住贴边使用系统保存的 `FloatHandleInfo` 和原生 `setFlexibleTaskOptions` 构造恢复参数，保留任务、坐标、缩放和原生展开动画。
- 桌面和贴边恢复不携带跨应用智慧跳转标志。该标志在本机原生实现中会删除相同组件的贴边任务，导致重建任务及丢失位置。
- 前台保活组合使用时，仅对本模块已停靠、经过过滤与应用锁检查且带有本次恢复标识的任务，使用保存的原生浮窗参数，避免系统复用迷你状态并排队退成全屏。

本机 `isPsPlusEnable` 及贴边锁定许可已经原生为真，移除对应的强制真值 Hook；保留具有实际增益的多模式判断和前台任务停靠处理。这不代表整个多模式或前台保活功能重复。

## AOD 默认与恢复

新配置的四项增强默认关闭，初始暗亮度、初始亮亮度及运行倍率默认使用系统值。配置读取失败时宿主按相同默认值运行；管理端保存的设置保留供连接恢复后重试。已有用户明确保存的选项按原值读取。

新增“恢复 AOD 系统默认”，仅重置 AOD 配置。默认时长为跟随系统；不会重置分屏、投屏或手势设置。

常用“全天全景息屏”同时提供后台全天能力及系统设置入口；仍需在系统的显示设置中选择“全天显示”。“仅显示全天设置入口”移至高级选项，在后台增强关闭时可单独使用。后台增强开启时显示已包含入口，保留用户之前的独立选择。

后台只覆盖全天能力，保留原生全景基础能力。逐实例保存原生字段，原生重新初始化前还原、完成后重新采样；切换配置时由主线程合并更新并调用原生能力发布方法。关闭后恢复最新原生值，下一次息屏使用新配置，无需为切换功能反复重启系统界面。首次安装或更新仍需重启手机加载代码。

## 显示与诊断

- “自定义小窗高宽比”明确为高度 ÷ 宽度，2 表示高度为宽度两倍；数值语义保持不变，旧配置无需转换。
- 配置页区分配置服务连接、设置保存及宿主加载。
- 分屏与小窗新增功能运行状态，报告系统框架所加载的模块版本、接口组是否完整、是否触发，以及最近启动是否观察到可见柔性窗口。
- 切换启动开关或应用过滤后清除旧结果，丢弃旧配置下的延迟观察。未知状态保持未知，不把已保存或调用过接口显示为功能已生效。
- 运行状态仅由应用主动请求，校验请求来源及随机标识；不列出其他应用，不后台轮询。启动观察每次一次、同时最多八次。

## 界面优化

主界面使用四个带颜色标识的入口卡片，连接状态、版本和适配设备集中显示；分屏、小窗、投屏和隔空手势页面统一返回按钮、标题、状态卡、分组标题、开关卡片和主操作按钮，减少默认控件样式混用。AOD 页面补充顶部说明卡，保留原有 Miuix 组件和无障碍文本。设置键、运行逻辑和包身份未因界面调整改变。

实机证据与验证范围见 [验证记录](evidence/optimization-1.5.0/validation.json)。长期功耗、全部应用、全部横竖屏与多用户组合不在本轮结论范围内。
