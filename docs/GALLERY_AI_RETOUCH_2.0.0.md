# 2.0.0 相册 AI 修图师与云端灵感推荐

适配对象：Find X7 Ultra / PHY110，PHY110_17.0.0.100(CN01)，Android 17 API 37；相册 17.10.66、相机 7.006.191。

相册增强页面现在有两个独立开关：AI 修图师和云端灵感推荐。AI 修图师只补齐相册的 `feature_is_support_ai_retouch` 支持判断；账号、网络授权、服务额度、图片条件、请求提交和另存为新图全部交给相册原生流程。云端灵感推荐只补齐相机的 `inspiration.support` 入口和内存中的功能表记录，同时关闭相机本地实时构图入口，避免把两套能力混在一起。

本机对照结果：关闭模块时，相册 AI 编辑菜单没有 AI 修图师；开启后出现 AI 修图师，输入 `Make colors warmer` 后进入原生结果页并能继续保存。相机云端推荐此前实测返回过 10–15 张推荐图，可选择并进入参考／跟拍页面；并非所有场景都成功。相机本地构图引擎在独立实测中虽能初始化供体算法，但真实推理失败，因此没有加入。

关闭任一开关后重新进入对应应用即可恢复原生入口。正式模块不保存取景图、推荐图、请求正文或账号信息，也不包含本地构图算法库和模型。
