# 2.1.7：移除互联增强，保留截图录屏

日期：2026 年 11 月 18 日。版本 **2.1.7／23**，已安装到 PHY110 完成专项实机回归。

删除 OPPO 互联的码率、分辨率、DPI、帧率、低带宽、机型、硬件和游戏增强，以及对应 Hook、策略、会话状态和宿主诊断。主页改为独立的“截图与录屏”入口，使用截图边框与播放符号的矢量图标。

保留 `window_capture/capture` 配置键和原有系统窗口 Hook。升级通过框架 API 删除退役参数及本模块的 `com.oplus.cast` 作用域；其他作用域和功能配置保留。更新后需打开模块完成迁移，并重启手机清除旧进程中的 Hook。

## 验证

- Release 构建及原签名验证通过；147 项单元测试通过，Lint 0 错误、31 警告。
- 真实升级移除 9 项已保存的投屏参数；作用域 11→10。截图录屏原开关值、其他功能配置、其他模块均保持一致。
- 用户重启后，系统框架报告 2.1.7，捕获必需接口加载成功；主页入口、设置页、状态页及真实开关保存通过。
- 合成安全窗口“关闭→开启→关闭”：截图像素黑→原色→黑，3 段录屏解码后亦黑→原色→黑；测试应用始终请求 FLAG_SECURE。最终恢复用户原来的开启状态。
- 原生投屏显示合成色块；投屏进程未映射本模块 APK，无投屏作用域。停止后 MediaProjection 会话结束、相关亮屏锁释放。不重复测试已经删除的帧率／码率档位，也未测量实际传输帧率。
- 完整日志中未见 Java FATAL EXCEPTION 或 ANR；未见已移除的互联 Hook 日志。开机 qti-testscripts 的 SIGABRT 与此前固件问题一致，按用户要求不处理。

## 额外观察及边界

测试配置工具切换模块进程时出现两次声音服务 Binder 断开警告。最终声音状态为“无法启动声音适配，请检查 Root 授权”：ADB 环境存在 `/system/bin/su`，模块进程挂载命名空间中对应文件不存在。声音代码本轮完全未改。2026 年 11 月 18 日，设备使用者确认尚未授予模块 Root 权限，将自行补充授权；本次记录归为未满足 Root 授权条件，授权后的声音状态尚未重新验证。Root 管理器设置保持原样。

本轮仅验证删减涉及的捕获、升级配置、界面、诊断和原生投屏链路。其他功能未重复全面实测。普通窗口安全标记不涵盖硬件 DRM 或应用主动隐藏内容。

## 清理

两个测试 APK 已卸载，包数据、用户配置目录、编译缓存和测试进程均核对无残留。三段测试视频及 UI 临时文件已删除，截图直接保存到电脑；手机 `/data/local/tmp` 恢复为空，共享存储与 MediaStore 未发现本轮测试文件。屏幕超时恢复 30 秒，截图录屏恢复原值，其他设置与模块保持一致。正常系统日志和用户应用数据保留。

完整脱敏结果见 [验证记录](evidence/capture-only-2.1.7/validation.json)。
