# 联网选项解锁与统一界面

适配：OPPO Find X7 Ultra（PHY110），ColorOS 17.0.0.100(CN01)，Android 17 / API 37；流量管理 `com.oplus.trafficmonitor` 17.3.5（17003005）。

## 使用

在 LSPosed 为 ColorOS 增强勾选“流量管理”，更新后重启一次。主界面新增“联网管理”，共五项入口。开启“显示全部应用的联网选项”后，退出并重新打开系统联网设置；应用选择与具体联网规则仍由 ColorOS 管理。

开关默认关闭。它只改变选项显示，不自动禁用应用联网。用户操作仍由系统原生的 `OplusNetworkingControlManager.setUidPolicy` 保存和执行。关闭解锁开关会恢复原生页面筛选，**不会清除已经设置的禁用规则**，需要在系统中自行恢复对应规则。

## 本机限制与适配

原生普通应用已经具有 WLAN、移动数据控制，不重复添加另一套控制。原生“软件更新”隐藏 WLAN 开关；“下载”等部分系统应用因 `DataUsageUtils.isDataApp` 分类被整组移除，简单将残留控件设为可见不能补回这些入口。

适配只在流量管理的应用列表构建及应用详情初始化中扩展系统应用分类，保留原生返回为真的情况；通过本机已核对的显示条件开放 WLAN 与移动数据选项。没有替换防火墙写入方法，没有伪造联网权限，也不修改全局 UID 身份。辅助推送、漫游与网络提示进程保持原样。

范围为有 INTERNET 权限、属于普通应用 UID 的可管理应用，包括系统应用。共享 UID 的应用共用同一联网规则；Android 核心身份无法按其中单个包隔离，继续使用原生处理。无联网权限、系统必要过滤、企业管理和行政限制不因本功能而解除。不能将这些项称为任意包均可单独断网。

适配器核对本机方法签名及常量特征，接口不符时保持原生行为。状态页显示宿主中加载的模块版本、解锁是否开启、是否触发系统应用分类扩展；它不把“选项已显示”当作“实际断网已生效”。

## 统一界面

主页、分屏与小窗、OPPO 互联、AOD、隔空手势、联网管理、运行状态页共用一套原生界面组件：返回、标题、分组、开关、数值对话框、状态卡和按钮。AOD 保留原有配置同步、数值校验、时长与重置逻辑；亮度滑块与输入集中在确认保存的对话框中。长连接说明收至可点击状态卡，五个入口可在本机主屏同时查看。

## 验证范围

关闭／开启／关闭分别记录软件更新、下载、普通临时应用、无联网权限临时应用和核心共享身份。临时应用通过原生控件写入策略，再退出重进读取保存结果，最终恢复策略 0；其他 UID 策略在测试前后比较。没有修改软件更新或下载等真实系统应用的联网规则。

联网验证核对原生 UID 策略的保存、回显和恢复，不发送测试流量，不将策略写入结果表述为已验证所有应用的真实流量阻断。移动数据链路、VPN／代理组合、跨用户、系统更新后的适配不在本轮结论范围内。

对应结果、构建信息和清理结果见 [验证记录](evidence/network-1.6.0/validation.json)。
