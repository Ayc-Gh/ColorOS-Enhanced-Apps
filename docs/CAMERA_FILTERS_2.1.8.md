# 2.1.8 相机滤镜补齐与实机验证

已完成适配、安装和专项测试，发布版本为 [GitHub v2.1.8](https://github.com/Ayc-Gh/ColorOS-Enhanced-Apps/releases/tag/v2.1.8)。设备为 PHY110 / ColorOS 17.0.0.100(CN01) / API 37，相机 7.006.191（60000）。独立开关位于“相机与相册 → 补齐相机滤镜”，全新安装默认关闭；本机已开启。修改后重启相机进程生效，不需要为这个开关重启手机。

人像和普通视频增加和光、浓郁、反差黑白三项。原有“明艳”“胶片”“大师人像”等按资源去重，不重复换名添加。大师模式使用自己的原生预设体系，本轮保持原样。复古相机、节日／氛围及 GR 专属模式还依赖对应模式、参数或配套资源，未列为已支持功能。

## 实现

- 使用现有宿主版本检查和原生滤镜列表，只追加资源及名称均可用的条目；不修改相机 APK、相机数据库或只读分区。
- 其他风格优先复用本机原生 LUT；和光、浓郁、反差黑白、冷／暖闪光和贾樟柯滤镜使用用户提供固件中的 OEM LUT。
- 30 份配套 LUT 共 3,850,212 字节，逐项校验 SHA-256；只存放在模块 APK 及相机进程的密封匿名内存中，不解压出手机临时文件。进程退出后描述符释放；校验或接口准备失败时保留原生列表。
- 反差黑白的强度控制是低／中／高对比度 LUT 插值。预览和成片均使用同一组合与插值规则，避免中间强度混回原图颜色。
- 滤镜适配独立处理失败，不阻断已有灵感推荐与 Log 接口。状态页区分进程开关、资源准备、需要重启及实际照片列表数量。

资源来源、逐项摘要及许可归属见 [资源清单](CAMERA_FILTER_RESOURCES_2.1.8.json) 和 [NOTICE](../NOTICE)。OEM LUT 不归项目 AGPL 软件许可证授权；未复制 OEM 可执行库或完整相机 APK。

## 实机结果

| 项目 | 结果 |
| --- | --- |
| 33 项新增后置照片滤镜 | 逐项选择并记录预览，保存 4096×3072 JPEG；核对菜单、预览、成片及实际 LUT 路径 |
| 人像三项胶片滤镜 | 逐项预览及实拍通过；使用静物，只验证色彩，不代表人物分割／景深质量验证 |
| 普通视频三项胶片滤镜 | 1080p / 30 帧 SDR；三段视频完整解码成功，抽帧与预览一致，反差黑白成片通道差为 0 |
| 关闭开关并重启相机 | 恢复原生 20 项，无匿名 LUT 描述符；旧新增索引由 OEM 截断到原生末项，测试后手动恢复原图 |
| 最终包诊断 | 已加载 2.1.8，照片滤镜共 53 项，安装包 SHA-256 与交付包一致 |
| 构建 | 153 项 JUnit 测试通过，Release lint 0 错误／32 警告，沿用既有签名 |

照片逐项实拍在人像／视频验证前的候选包上完成。随后取消未使用的大师模式追加并补充状态文字，照片处理逻辑未改变；最终签名包额外验证三项普通视频滤镜和 53 项照片状态，没有重新拍摄已通过的全部照片。未重跑其他模块功能，也未声称覆盖前置、所有焦段、HDR、RAW、Log 等组合。

调试期间修复过 ashmem 无法由 native 文件接口读取、匿名路径失去伴随 LUT、OEM 强度字段实际为 float 等问题。异常原型和菜单动画吞掉切换动作产生的重复样本均未计入通过结果。
