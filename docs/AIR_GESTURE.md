# 隔空手势适配

主界面保留“隔空手势”入口，用于开启额外的隔空滑动、暂停／播放设置入口。AON（感知与手势识别）和 AOD（息屏显示）是不同组件，分别设置。

## 当前实现

- 仅在 `com.oplus.gesture` 的主进程和设置进程中开放额外设置查询。
- 保留原生调用、原有隔空接听与静音能力，不改写 SensorHub、Explorer、识别模型、相机权限、应用支持列表或系统手势开关。
- 配置键为 `window_capture/air_gesture_entries`，默认关闭，独立于窗口、投屏和 AOD 设置。
- 系统设置、支持的应用和实际识别行为继续由 ColorOS 管理；模块页面不代替系统设置流程。

## 设备分析

本机适配目标为 OPPO Find X7 Ultra / PHY110、ColorOS 17.0.0.100(CN01)、Android 17。分析确认 AONService 与手势体感存在引擎互斥条件，因此模块不向 AONService 增加引擎强制开关，也不在页面内控制系统组件生命周期。

## 使用范围

在 LSPosed 为本模块勾选“手势体感”，打开“隔空手势”页面并按需开启入口。原有接听、静音、系统手势开关和支持的应用由系统管理。额外入口的显示不代表所有应用均支持对应手势。

## 验证边界

历史实机测试确认额外入口和原生识别链路可用；本版本删除了模块内的组件重启操作、系统手势学习入口及设备提示语，避免重复提供系统功能。当前回归只验证页面删减、开关保存、宿主加载和既有模块设置不受影响，不将页面显示扩大为所有应用兼容性结论。
